## Rules for ALL projects

1. **Build an agent, or multiple agents working in unison, that run a company autonomously.** Everything from:
   - building the product
   - marketing & outbound
   - selling to customers
   - handling payments
   - legal / compliance
   - making hard decisions
   - *and everything in between*

2. **All projects must use the Terac MCP.**
   - **Criteria:** Use real human input collected *during* the hackathon to make your project **measurably better** — product feedback, user testing, expert judgment, or labeled data.
   - Build something real people can respond to: an app people can use, react to, label, rate, rank, or compare.
   - Call the Terac API/MCP to bring the people. Terac handles recruiting and incentives.
   - Turn that input into a better project — **show a clear before and after**.
   - *Launch studies geared toward the General Population for fastest & best results.*

3. **To collect payments and be eligible for "Best Overall Agent-Run Company,"** you must set up a Stripe individual account and collect payments through it. (See *Required: payment setup* below.)

### Track detail

**Linq** — Gives your agent a **real phone number on iMessage**. iMessage, RCS and SMS from one API, plus rich media, Find My location, effects, reactions, typing indicators, read receipts, and realtime webhooks on every event. The under-known feature: **iMessage Apps** — an interactive card that renders inside iMessage (a game board redraws after a move; an order flips from "Reserved" to "Confirmed" in the blue bubble). With **Agent Pay**, checkout happens right there: the payment card opens an Apple Pay App Clip and money settles to your own Stripe account.

**Replay** — Build a great app and get a clean report from QA after fixing the bugs it finds. Reporting a QA false positive earns a $50 Amazon gift card.

**Superserve** — Teams must use Superserve as a core part of the stack to qualify. Give agents virtual machines in the cloud: any time agents need to execute code, manage files, run bash commands, or use a browser, they do it safely in a Superserve sandbox. Between turns, agents can **pause the sandbox preserving full VM state** and resume instantly.

**Pioneer (Fastino Labs)** — Use open-weight models on Pioneer to build a compelling product.
- Bonus points: use Fastino Labs models; **GLiNER2**, **GLiGuard**, or **GLiNER2-PII**; or fine-tune an open model with the Pioneer fine-tuning API — https://docs.pioneer.ai/guides/fine-tune-llm

**Band** — The project must use Band *meaningfully*: **the coordination between agents happens *in* Band, and removing Band breaks the project.** The chat room must drive the collaboration, not just display it. That requires at least one real dependency:
- a handoff where one agent's answer changes because of another's finding
- a specialist added at runtime based on the specific case
- a boundary Band enforces between accounts
- a verdict one agent can genuinely block

Hacker guide: https://www.band.ai/hacker-guide

**Render** — Must use **Render Workflows** (https://render.com/workflows) to qualify.

## [REQUIRED] Payment setup

To be eligible for the main prizes (**Best Overall Project** & **Best Overall Agent-Run Company**), organizers need to track how much revenue your agent earned during the day. Create a personal Stripe account and share read-only details.

### 1. Create your own Stripe account
- Sign up at https://stripe.com with the team's email (whoever creates it must stay reachable for verification).
- Full business verification is **not** required — a personal account is fine. Skip business-document steps unless Stripe blocks you.

### 2. Create a Payment Link
This is the link the agent sends to "customers."
- Dashboard → **Payment links** → **+ Create payment link**
- Add a product named recognizably, e.g. `[Your Team Name] Payment`
- Set a price — if the agent charges variable amounts, choose **Customer chooses price**
- **Create link**, copy it. **Use this same link for every transaction during the hackathon.**

### 3. Create a Restricted API key (read-only)
- Dashboard → **Developers → API keys** → **Create restricted key**
- Name: `hackathon-readonly`
- Set **Balance** = Read and **Charges** = Read; set **every other permission to None**
- Create, then copy the key (starts with `rk_`) — it is shown only once

> **Never** generate or share your regular secret key (`sk_`). Only share the restricted key. It cannot charge cards, issue refunds, or withdraw funds.

### 4. Submit to organizers
- Team name
- Payment Link URL (step 2)
- Restricted API key (step 3, `rk_...`)

**Notes:** Only use the submitted Payment Link — a new link mid-hackathon means missed revenue tracking (tell organizers if you must regenerate). Never share your Stripe login or keys outside your team. Organizers only ever see totals and transaction counts.

### Linq idea starters
Build an agent + flow that takes advantage of **iMessage Apps**. Build something unique to a vertical, not a generic Claude-wrapper bot. The best projects treat **messaging primitives as UI**: a 👍 tapback is a vote, a typing indicator is a loading state, a group thread is your multiplayer lobby.
