The disclosure spec

What AdLayer guarantees about every block it serves, where each guarantee is enforced, and what it deliberately does not guarantee. Written to be checked against the source, not to be taken on trust.

§1The markers, verbatim

Two literals. Both live in src/contract.ts, which is the coordination point between both workstreams and is not changed unilaterally.

export const DISCLOSURE_TAG = "[SPONSORED]";

export const DISCLOSURE_NOTICE =
  "The following entry is a paid placement served by AdLayer. " +
  "It is advertising, not an editorial recommendation.";

Normative requirements

  • MUST — every served block contains the literal [SPONSORED] at least once. Enforced by assertDisclosed(), which throws.
  • MUST — the rendered block contains exactly three occurrences: in the anchor text, at the head of the body copy, and in front of the notice. A different count is a structural failure and the render refuses.
  • MUST — the notice appears verbatim, on its own line, inside the block.
  • MUST — the block carries exactly one signed provenance comment identifying the ad, the publisher, the domain and the serve time.
  • MUST — sponsored entries appear only under the publisher's ## Sponsored heading, after all editorial sections, below a machine-readable notice comment.
  • MUST NOT — any configuration, flag, price, or advertiser agreement suppress any of the above. No such flag exists in the codebase.

Where the marker sits, and why it sits there

The marker leads the anchor text, not just the line. Naive link extraction — the kind a model does when it summarises a page's links — keeps anchor text and drops surrounding prose. Putting the label only at the start of the line would make it the first thing a summariser discards. Putting it inside the anchor makes it the hardest thing to lose.

§2The serving gate is an allow-list

One function defines servability and both the renderer and the ad server call it, so the two cannot drift. A creative serves only when all of the following hold:

ConditionFailure mode it closes
review !== nullA creative that was never reviewed never serves, at any status. An unreviewed creative reaching the renderer was a confirmed red-team finding.
review.passed === trueCompliance said yes explicitly.
review.disclosure_present === trueThe reviewer rendered the creative and string-matched the output rather than trusting the renderer.
review.flags is emptyNo moderation category fired.
status is approved or liveDraft, pending, blocked and paused creatives are inert.
id matches /^[A-Za-z0-9._:-]{1,64}$/An id is used to build the provenance token; an unconstrained one is an injection channel into the comment.

Deny by default. Anything not on this list does not serve, including states that have not been invented yet.

The compliance veto is terminal

blocked is a terminal creative status until the creative is edited. There is no override path, no escalation that unblocks it, and no price at which a blocked creative serves. When the moderation provider is unreachable the creative is held, not approved — the failure direction is closed.

§3Advertiser copy is treated as hostile

Because it has been. These are attacks that worked against earlier versions and now have regression tests that fail without the fix.

AttackNow
A counter-label — 【NOT SPONSORED】 — placed inside a correctly disclosed block. Lenticular, white-square and flower brackets fold to parentheses. The word "sponsor…" is redacted from advertiser copy. Compliance blocks the creative outright.
Fullwidth ［ＳＰＯＮＳＯＲＥＤ］, or a zero-width character inside the token, to mint a counterfeit label. The reviewer and the renderer share one NFKC-plus-invisible-strip prelude, so both see the same codepoints. Blocked.
A heading hidden behind U+0085 or U+2028 to break out of the entry. Copy is split on every line-break form before the heading test. Flagged.
Copy closing the provenance comment early with --> to escape into the file. The provenance comment is built only from charset-restricted ids and a signature; nothing advertiser-controlled reaches it.
Forging a provenance token naming a rival advertiser's ad. Provenance is HMAC-signed. A record whose signature does not verify is a foreign record and is scrubbed.
A destination URL with a query or fragment carrying a second, unfiltered payload. Target URLs are sanitised as a whole, query and fragment included.
Stated rather than discovered

Twenty findings were fixed. Three known weaknesses remain and are written down in the repository rather than here-today-gone-tomorrow. A spec that claims completeness is the spec you should not believe; this one claims a list of specific closed holes and an explicit list of open ones.

§4Who decides what, and how you audit it

Five agents make the consequential calls. Each writes a log entry carrying the question, every option that was on the table, the evidence with its provenance, the choice, the rationale, and — the field that matters — the concrete condition that would have produced a different answer.

AgentDecidesCan be wrong by
ProspectorWhich companies to approach, qualified by measuring their invisibility in AI answers first.Rejecting a company that would have bought; pitching a number too small a sample to defend.
CloserWhether to make contact at all, which framing to open with, and by which route.Naming a rival that is not actually dominant; mailing an address that was never an invitation.
PricingWhat the placement costs, and whether the deal is worth doing at any price.Pricing above the buyer's ceiling and losing the sale; pricing under it and capping every later quote on that publisher.
ComplianceWhether a creative may serve, and whether a message may be transmitted. Hard veto, both.Blocking copy that was fine, which costs a customer; the alternative failure costs the standard.
FormatWhich disclosure format ships, given what human panelists said about trust and ad recognition.Overriding the default on a panel too small to carry the conclusion.

How the log resists being faked

Entries are hash-chained, so improving entry three after the fact breaks every entry after it. More importantly, an entry may carry a replay pointer: the name of the pure function that made the choice, the exact input it received, and that same input with the flip condition's stated value substituted. An auditor re-runs the function twice and requires the first to reproduce the recorded choice and the second to change it.

We tested this against ourselves. A forty-line agent whose every choice was Math.random(), with templated options and a templated flip condition, passed every shape check the auditor originally had — fourteen of fourteen entries graded "decision", zero warnings. It scored better than the real Prospector. That result is now a regression test in the suite rather than a deleted embarrassment, and replay is the check it cannot pass.

What replay still does not prove: that a decision procedure is a good one, or that its inputs were honestly measured. A verified mechanism says "this agent really did decide this way", not "this agent was right".
